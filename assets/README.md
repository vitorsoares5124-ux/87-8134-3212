# assets/ — fotos reais da página

Coloque aqui os arquivos com EXATAMENTE estes nomes:

- produto-hero.png  → embalagem com transparência (hero, cópia exata do original)
- produto-hero.jpg  → mesma foto otimizada (âncora da fórmula)
- kit-1-mes.png     → kit de 1 mês
- kit-3-meses.png   → kit de 3 meses
- kit-5-meses.png   → kit de 5 meses
- kit-12-meses.png  → kit de 12 meses (quando chegar a foto real)

O código detecta automaticamente: se o arquivo existir, a foto aparece;
se não existir, o visual CSS de reserva continua no lugar.

Dicas: exporte em JPG/PNG otimizado, largura máxima ~1200px.
